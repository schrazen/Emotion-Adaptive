# Collaborator Setup

## Requirements
- Node.js LTS
- VS Code

## Install
1. Open the project root in VS Code.
2. Run:
```powershell
npm install
```

## Run
```powershell
npm start
```

## Notes
- Commit `package.json` and `package-lock.json`.
- Do not commit `node_modules`.
- Do not commit local database files.
